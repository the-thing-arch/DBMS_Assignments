# 📘 DB Lab 6 – Data Aggregation using GROUP BY and HAVING

## 📌 Objective

This lab focuses on understanding how to summarize and analyze data using **SQL aggregate functions**, along with:

- GROUP BY clause for grouping data  
- HAVING clause for filtering grouped results  
- Aggregation with JOIN operations  
- Generating meaningful reports without modifying stored data

## 🧠 Concepts Covered

- HAVING clause (filtering grouped data)

## 🗂 Lab Structure

### 🔹 Part A: Basic Aggregate Queries
1. Total number of students  
2. Total number of faculty members  
3. Total number of courses  
4. Maximum course credits  
5. Minimum course credits  

### 🔹 Part B: GROUP BY on Single Tables
6. Students in each department  
7. Faculty in each department  
8. Courses per department  
9. Enrollments per semester  
10. Students per grade  

### 🔹 Part C: GROUP BY with HAVING

12. Semesters with more than 2 enrollments  
13. Grades assigned to more than one student  
14. Departments offering more than one course  

### 🔹 Part D: Aggregation with JOIN
15. Students enrolled in each course  
16. CourseName with number of enrolled students  
17. Department-wise student count  
18. Faculty with number of courses taught  

### 🔹 Part E: Analytical Queries
19. CourseName with maximum grade  
20. Department-wise total courses  
21. Semester-wise total enrollments  
22. Courses with more than 2 students enrolled

## ⚠️ Important Instructions

- Use **aggregate functions correctly**  
- Apply **GROUP BY** wherever grouping is required  
- Use **HAVING** for filtering grouped results  
- Combine **JOIN with aggregation** when needed  
- Do not modify table structure  
- Insert data only if necessary for meaningful output
