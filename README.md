# Database Management Systems (DBMS) Assignments

This repository contains the complete set of **Database Management Systems (DBMS)** course assignments for B.Tech CSE.

It includes assignment questions along with their corresponding **MySQL scripts**. All SQL files were executed and tested using **MySQL Workbench**.

Each assignment is organized in a separate folder to ensure better structure, clarity, and ease of access.

---

## 📌 Repository Features

- Well-structured assignment folders
- MySQL-compatible SQL scripts
- Executed and tested using MySQL Workbench
- Proper use of:
  - Primary Keys
  - Foreign Keys
  - Constraints
  - Data insertion
  - Query execution
- Clean formatting and well-documented SQL code

---

## 🛠 Tools & Technologies Used

- **Database:** MySQL  
- **Query Language:** SQL  
- **Tool Used:** MySQL Workbench  

---

## 🎯 Learning Objectives Covered

- Database design and schema creation  
- Table relationships and normalization  
- Data insertion and validation  
- Constraint enforcement  
- Query writing and execution
